## 2. テーマ逆引き検索ページ（公開）

### レイアウト

```
+--------------------------------------------------+
| テーマ逆引き検索                                   |
| 答えにしたい単語から、使えるテーマを逆引きします      |
|                                                  |
| 答えの単語                                        |
| +------------------------------+  [ 検索 ]       |
| | ひかり                        |                 |
| +------------------------------+                 |
|                                                  |
| ▼ 検索オプション                                  |
|   許容する未マッチ文字数  [ 0 ▼ ]                 |
|   [x] 表記ゆれ（濁点・半濁点・小さい音）を区別しない |
|   [ ] 同じ要素から2文字以上拾うことを許可する        |
|                                                  |
| ---- 検索結果: 2件 ----------------------------- |
|                                                  |
| +----------------------------------------------+ |
| | 指の名前                        カテゴリ: 日常 | |
| |                                              | |
| |  おや  【ひ】とさし  な【か】  くす【り】  こ   | |
| |                                              | |
| |  【ひ】とさし                                 | |
| |  な【か】                                     | |
| |  くす【り】                                   | |
| +----------------------------------------------+ |
|                                                  |
| +----------------------------------------------+ |
| | （次の候補グループ）                            | |
| +----------------------------------------------+ |
+--------------------------------------------------+
```

### 挙動

- 検索はブラウザ内で完結する。ページ初回表示時に辞書JSONを読み込む（読み込み中はスピナー表示）
- 「検索」ボタン押下で実行。Enterキーでも実行できる
- オプション変更時、既に結果が表示されていれば即座に再検索する
- 入力バリデーション: ひらがな・カタカナ・半角英字以外を含む場合、入力欄の下にエラーメッセージを表示
- 結果カード:
  - グループの全要素を並び順どおりに表示し、拾った文字を【】等で強調表示する
  - その下に、拾い元の要素を答えの文字順に縦に並べ、それぞれ拾った文字をハイライトして表示する
  - 未マッチ文字がある場合: リストに「「り」は拾えません」のように赤系で表示し、カードに「1文字拾えません」バッジを付ける
  - 拾い方が複数通りある場合: カード下部に「▸ 他の組み合わせ N件」トグルを表示。開くと各組み合わせが1行ずつ（ハイライト付き）並び、クリックでカードの表示をその組み合わせに切り替えられる。読み替え（濁点等の同一視）に頼らない組み合わせを優先して代表・並び順に採用し、読み替えを含む行には「読み替えN文字」バッジを付ける
- 並び順: 未マッチ文字数の昇順 → グループ名の五十音順
- 0件時: 「見つかりませんでした。『許容する未マッチ文字数』を増やすと候補が見つかるかもしれません」と案内を表示

## 3. 管理画面（ローカル起動のみ）

`npm run admin` 等でローカルサーバーを起動してブラウザで開く。公開ビルドには含まれない。
画面上部に常に「ローカル管理モード」バナーを表示し、公開サイトと取り違えないようにする。

### 3.1 グループ一覧

```
+--------------------------------------------------+
| [ローカル管理モード] 辞書管理                       |
|                                                  |
| [検索: グループ名・要素____]  [カテゴリ: すべて ▼]  |
| [+ 新規グループ]  [一括インポート]                  |
|                                                  |
| | グループ名   | 要素数 | カテゴリ | 公開 | 更新日 | |
| |------------|-------|---------|-----|-------| |
| | 指の名前     |   5   | 日常    | 公開 | 9/2   | |
| | 曜日        |   7   | 教育    | 公開 | 9/2   | |
| | ...        |       |         |     |       | |
+--------------------------------------------------+
```

- 行クリックでグループ編集へ
- 検索欄はグループ名・要素の部分一致で絞り込み

### 3.2 グループ編集

```
+--------------------------------------------------+
| グループ編集: 指の名前              [削除]         |
|                                                  |
| グループ名 [指の名前_______________]              |
| カテゴリ   [日常 ▼]     公開 [x]                 |
|                                                  |
| 要素（ひらがな or 半角英字のみ・並び順あり）         |
|  ≡ [おや______]        [×]                      |
|  ≡ [ひとさし____]       [×]                      |
|  ≡ [なか______]        [×]                      |
|  ≡ [くすり_____]        [×]                      |
|  ≡ [こ_______]         [×]                      |
|  [+ 要素を追加]                                   |
|                                                  |
| 備考 [_____________________________]             |
|                                                  |
|                        [キャンセル] [保存]        |
+--------------------------------------------------+
```

- 要素は「≡」ハンドルのドラッグ&ドロップで並べ替え
- 要素入力時にリアルタイムでバリデーション（ひらがなのみ or 半角英字のみ。違反時は欄を赤くしてエラー表示）
- 要素追加はEnterキーで次の入力欄を作り、連続入力できるようにする（大量登録の効率優先）
- 保存で辞書マスターJSONに書き込む。同名グループが既に存在する新規登録時は警告を表示
- 削除はグループ全体の削除。確認ダイアログを挟む

### 3.3 一括インポート

```
+--------------------------------------------------+
| 一括インポート                                     |
|                                                  |
| 1行1グループで貼り付けてください                    |
| 形式: グループ名: 要素, 要素, ...                  |
| +----------------------------------------------+ |
| | 指の名前: おや, ひとさし, なか, くすり, こ       | |
| | 曜日: にち, げつ, か, すい, もく, きん, ど       | |
| | ...                                          | |
| +----------------------------------------------+ |
|                          [プレビュー]             |
|                                                  |
| ---- プレビュー ------------------------------- |
| ○ 指の名前（5要素）                               |
| ○ 曜日（7要素）                                  |
| × 3行目: 要素「火」に使えない文字が含まれています    |
| △ 4行目: 「干支」は既に存在します（スキップ）        |
|                                                  |
| 取り込み対象: 2件            [取り込み実行]        |
+--------------------------------------------------+
```

- プレビューで行単位の成否を表示し、正常な行のみ取り込む
- エラー行・重複行は理由付きで一覧表示する

## 4. 公開反映フロー（運用）

1. ローカルで管理画面を起動し、辞書を編集（→ 辞書マスターJSONが更新される）
2. 変更を確認して commit & push
3. 静的ホスティング側のビルドで公開サイトに反映される
