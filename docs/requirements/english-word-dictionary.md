# 要件定義: 平易な英単語辞書（英語版トレーニングの下準備）

- サイト全体: 謎解きツール集「謎蔵（Nazogura）」
- 本書の対象: 能力向上ツールの英語版に向けた単語辞書の整備（ツール本体は別要件）
- 作成日: 2026-09-04
- 状態: **計画のみ・実装未着手**（利用制限による中断のため、再開用に経緯を残す）

## 1. 背景・目的

能力向上ツール（五十音文字拾い・五十音シフト・アナグラム）を英語に広げたい。
想定しているツール案:

- A=1式変換トレーニング（14-1-26-15 → NAZO を反射で戻す）
- 英単語アナグラム
- アルファベット拾い系

これらの答えに使える、**日本人が中学までに習う水準の平易な英単語辞書**を用意する。

要望（2026-09-04）:

- am / the / be のような**機能語は含まない**
- **3文字以上**に絞る

## 2. 出典の選定（調査済み）

文科省公式の中学英単語リストは存在しない（指導要領は語数の目安のみで、語彙は教科書会社ごとに異なる）。
調査の結果、以下を採用する。

### 採用: CEFR-J Wordlist Version 1.6（東京外国語大学 投野由紀夫研究室）

- 入手先: http://www.cefr-j.org/download.html （`data/CEFRJ_wordlist_ver1.6.zip`、Excel形式）
- A1レベル: 1,166項目 ≒ 小〜中1 / A2レベル: 1,411項目 ≒ 中2〜高1 → **A1+A2 ≒ 中学までの語彙**
- **品詞タグ付き**のため、機能語（冠詞・be動詞・代名詞・前置詞・助動詞・接続詞など）を機械的に除外できる
- ライセンス: 無償。研究・教育・商用とも**出典明記で利用可**。クレジット形式:
  「『CEFR-J Wordlist Version 1.6』東京外国語大学投野由紀夫研究室 (URL: … より◎年◎月ダウンロード)」

### 不採用の候補

| 候補 | 理由 |
|---|---|
| NGSL（2,809語、CC BY-SA 4.0） | 英語圏頻度ベースで機能語が多く品詞情報なし。頻度順ソートの補助になら使える |
| 英検級別・SVL12000・JACET8000 | 再配布不可 |
| 教科書（NEW HORIZON等）の語彙 | 著作権上、再配布不可 |

## 3. 変換方針

豚辞書（`scripts/convert-words.mjs`）と同じ流儀で、変換済みリストのみを同梱する。

1. CEFR-J zip をダウンロードし、Excel から A1+A2 の見出し語と品詞を抽出
2. フィルタ: 品詞で機能語を除外（名詞・動詞・形容詞・副詞を残す）
   → 3文字以上 → 小文字化 → スペース・ハイフン入りの複合語は除外 → 重複除去
3. `scripts/convert-cefrj.mjs`（新設）で `public/data/words/english.txt`（1行1単語）を生成
4. README・LICENSE にクレジット表記を追記（豚辞書の記載と同じ体裁）
5. **生のExcelはリポジトリに同梱しない**（配布はあくまで変換済みリスト＋出典明記）
