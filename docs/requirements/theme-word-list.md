# 要件定義: テーマ別単語リスト（暗記支援）

- サイト全体: 謎解き制作支援ツール集「謎蔵（Nazogura）」
- 本書の対象: 第2弾ツール「テーマ別単語リスト」
- 作成日: 2026-09-03

## 1. 背景・目的

テーマ逆引き検索（第1弾）は「答えの単語 → テーマ」の逆引きだが、制作の現場では逆に
「このテーマからどんな答えの単語が作れるのか」を一覧で眺めて、出題候補を把握・暗記したい。

本ツールは、辞書に登録された各グループ（テーマ）について、**その要素から1文字ずつ拾って
作ることのできる単語**を、平易な単語リストの中から探して一覧表示する。

## 2. 単語リスト（3辞書）

出典: プライベートリポジトリ `Hamaguri-0414/wordSearch` の以下3ファイル（UTF-8・1行1単語）。

| 呼称 | 元ファイル | 収録単語数 |
|---|---|---|
| 豚辞書 | buta014.dic | 201,092語 |
| 一般辞書 | buta014_common.dic | 48,545語 |
| コア辞書 | buta014_core.dic | 18,068語 |

- 全単語はひらがな+長音「ー」のみ、2〜8文字（取得時に検証済み）
- `scripts/convert-words.mjs` で改行正規化・検証・件数集計を行い、
  `public/data/words/<id>.txt` と `public/data/words/index.json`（呼称・ファイル名・件数）に変換して同梱する
- 画面には各辞書の収録単語数を表示する
- 変換済み単語リストは公開サイトで配信される（豚辞書はフリー配布の単語集）

## 3. 機能要件

### 3.1 グループ更新への追従

- 単語リストの事前生成は行わない。ページ読み込み時に最新の `public/data/dictionary.json` を取得し、
  **作れる単語の判定はすべてブラウザ内でその場計算**する
- これにより、管理画面（第1弾のadmin）でグループを追加・修正したら、本ページをリロードするだけで反映される

### 3.2 画面機能

- **辞書切替**: 豚辞書 / 一般辞書 / コア辞書 をタブで切替（各収録単語数を併記）。初期選択はコア辞書（最も平易・軽量）
- **オプション**: テーマ逆引き検索と同じ判定ルール
  - 濁音・半濁音・小さい文字は区別しない（初期OFF＝区別する）
  - 同じ要素から2文字以上拾うことを許可する（初期OFF）
  - 未マッチ許容は無し（単語全体を構成できる場合のみ採用）
- **グループ一覧**: 公開中の全グループを辞書登録順に表示し、それぞれ**作れる単語数**を併記する。
  件数計算は選択中の辞書に対してバックグラウンドで進め、進捗を表示する
- **単語一覧**: グループを選択すると、要素と作れる単語の一覧を表示する。単語は文字数ごとに区切って**文字数の多い順**に並べる（長い単語ほど希少価値が高いため）。区切り内は五十音順

### 3.3 判定ルール

テーマ逆引き検索と同一のマッチングを用いる（共通ロジックを共有する）。

- 単語の各文字を、グループ内の要素から1文字ずつ拾えるか（オプションOFF時は1要素1文字、二部グラフの最大マッチングで判定）
- 高速化のため事前フィルタを行う: 単語長が要素数を超える場合（複数拾いOFF時）、または
  グループ全体の文字集合に含まれない文字を持つ場合は即座に除外

## 4. 非機能要件

- 豚辞書（約20万語）× 全グループ（現在57件）の件数計算でも、UIをブロックせず数秒以内に完了すること
- 第1弾と同じ静的ホスティング構成（`https://hamaguri.dev/nazogura/tools/theme-word-list/`）
- 単語リストは選択された辞書のみオンデマンドで読み込む（豚辞書は約3.7MB、初期表示ではロードしない）
